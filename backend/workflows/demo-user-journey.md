# Demo User Journey

First working journey:

1. User opens Manzzzl AI.
2. User enters the app.
3. Creates a house project.
4. Selects city and floors.
5. Uploads a 2D plan.
6. System starts analysis.
7. User answers unclear plan questions.
8. User confirms understanding.
9. System prepares 3D exterior result.

This is the first complete MVP flow.
