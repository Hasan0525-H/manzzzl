# Manzzzl AI - منزلي AI

## الرؤية
تحويل مخطط المنزل إلى نسخة رقمية واقعية وفق العمارة والهندسة السعودية.

## المرحلة الأولى
- Android فقط.
- شاشة دخول بسيطة.
- رفع مخطط 2D / PDF لاحقاً DWG و Revit.
- تحليل المخطط مع أسئلة ذكية عند عدم وضوح أي جزء.
- إنشاء نموذج 3D خارجي قابل للدوران والتكبير والتصغير.
- إنتاج صور واقعية من نفس النموذج.
- منزل نهائي قبل التأثيث بدون أثاث.

## قواعد أساسية
- المخطط هو المصدر الأساسي ولا يتم تغيير التوزيع الهندسي.
- الذكاء الاصطناعي يستخدم للتحسين والواقعية وليس لاختراع غرف أو عناصر غير موجودة.
- التركيز الأول: جدة، أبها، محايل عسير، جازان.

## المستقبل
- الدخول داخل المنزل.
- المشي والصوت والتفاعل.
- مراحل البناء والتأثيث.
