# Manzzzl AI MVP Roadmap

## Phase 1 - Foundation
- Android application shell
- Login screen
- User private workspace
- Project creation

## Phase 2 - Plan Understanding
- Upload image/PDF
- Detect walls, rooms, doors and windows
- Ask user questions when confidence is low

## Phase 3 - Digital House
- Generate 3D structure
- Exterior 360 view
- Realistic rendering

## Phase 4 - Advanced
- Interior exploration
- Voice navigation
- Smart modifications

## Current Scope
Only exterior visualization first. No furniture generation.
