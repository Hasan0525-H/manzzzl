# Manzzzl AI - Technical Architecture Plan

## Goal
Convert Saudi residential 2D plans into realistic pre-furnished digital homes.

## Core Flow
1. User opens Android app.
2. User uploads a plan image/PDF.
3. AI analyzes architectural elements.
4. Missing information is requested through smart questions.
5. A 3D house model is generated.
6. Realistic exterior renders are produced.

## Rules
- The uploaded plan is the source of truth.
- AI must not invent rooms or change dimensions.
- Saudi architecture knowledge improves materials and appearance only.

## Future Ready

- Construction stages.
